## Conventions

- The gap marker in every prompt is `___` (`DrillItem.GAP_MARKER`); prompts are copied verbatim
  from `DrillSeparableVerbs.kt`.
- Rules are shared across many items (design §3: the rule and table belong to a rule, not to each
  item), so **miss lines are written per wrong-choice pattern**, not per item. Each pattern line
  names the wrong choice, says why it is wrong, and gives the right form for the item at hand.
- Tables below carry no highlight: before an answer every row and cell has equal weight. The
  matching row or cell is marked only in flashcard and after-answer states (design §2, §4).
- None of the existing rule IDs (`art-gender-*`, `prep-*`) covers a verb-prefix rule, so all IDs
  here are new, in the `sep` family.

## sep-dual

**id**: `sep-dual`

**items**: (20 — kind 1 and kind 2 for the ten dual-prefix verbs, über, um, unter, durch, wieder)

- Das Verb „durchlesen“ ist ___.
- Partizip II von „durchlesen“: ___
- Das Verb „durchqueren“ ist ___.
- Partizip II von „durchqueren“: ___
- Das Verb „wiedersehen“ ist ___.
- Partizip II von „wiedersehen“: ___
- Das Verb „wiederholen“ ist ___.
- Partizip II von „wiederholen“: ___

**rule (pre-answer)**: über, um, unter, durch, wieder: the meaning decides. Separable: prefix to
the clause end, ge- inside the participle. Inseparable: neither.

**first_exposure_rule**: none — no case or gender name applies, and naming this verb's group would
name the kind-1 answer, which no pre-answer field may do.

**forms table**:

| | Infinitiv | Hauptsatz | Partizip II |
|---|---|---|---|
| trennbar | umkehren | Ich kehre um. | umgekehrt |
| untrennbar | überleben | Ich überlebe. | überlebt |

(The example verbs umkehren and überleben are not drill items.)

**example (flashcard and after a miss)**: Ich kehre morgen **um**. Ich **über**lebe die Prüfung.

**miss lines**:

Kind 1, one per wrong choice:

- ✗ *untrennbar*: this verb's meaning puts it in the splitting group — its prefix detaches to the
  end of a main clause, so trennbar.
- ✗ *trennbar*: this verb's meaning keeps the prefix attached in every form, so untrennbar.

Kind 2, per wrong-choice pattern:

- ✗ ge- in front of the prefix (geüberkocht): ge- never stands before these prefixes. The
  splitting twin puts it inside (umgezogen); the attached twin takes none (überprüft).
- ✗ ge- inside an attached twin (übergeprüft): only the splitting twin takes ge- inside; this
  verb's participle stays plain, so überprüft.
- ✗ ge- missing from a splitting twin (überkocht): überkochen splits, so ge- goes inside:
  übergekocht.
- ✗ the present or infinitive form (umzieht, umziehen): that is not a participle; build it from
  the participle stem, so umgezogen.
- ✗ the -et ending (überprüfet, umarmet, untersuchet, durchqueret, wiederholet): the participle
  takes plain -t: überprüft, umarmt, untersucht, durchquert, wiederholt.
- ✗ the wrong ending on a splitting twin (übergekochen, durchgelest, wiedergeseht): kochen is
  weak and takes -t; lesen and sehen are strong and take -en: übergekocht, durchgelesen,
  wiedergesehen.
- ✗ the simple past (wiederholte): that is the past tense, not the participle: wiederholt.

**flashcard_and_miss_hint**: Each dual verb has one fixed group — learn it with its meaning:
umkehren splits, überleben does not.

**later_rung_cue**: Which group does this verb's meaning put it in?

**rule (pre-answer)**: Where ge- goes depends on the prefix: a separable prefix takes ge- after it (abgeholt), an inseparable prefix takes no ge- at all (beantwortet).

**first_exposure_rule**: none — no case or gender name applies.

**forms table**:

| | Infinitiv | Partizip II |
|---|---|---|
| einfaches Verb | machen | gemacht |
| trennbares Verb | abholen | abgeholt |
| untrennbares Verb | beantworten | beantwortet |

(The whole contrast set of where ge- sits; the example verbs are not drill items.)

**example (flashcard and after a miss)**: Ich habe dich am Bahnhof ab**ge**holt.

**miss lines**: (per wrong-choice pattern)

- ✗ ge- in front of the prefix (geanrufen): ge- belongs between the prefix and the stem, never in
  front, so angerufen.
- ✗ a weak -t on a strong verb (angeruft, zurückgekommt, mitgebringt, mitgenehmt): this verb
  is strong or irregular, so its participle ends in -en or has its own stem: angerufen,
  zurückgekommen, mitgebracht, mitgenommen.
- ✗ an -en ending on a weak verb (aufgemachen, ausgefüllen, vorgestellen): this verb is weak,
  so its participle ends in -t: aufgemacht, ausgefüllt, vorgestellt.
- ✗ the umlaut dropped and -en added (aufgehoren, zugehoren): hören is a weak verb; it keeps
  its stem and takes -t: aufgehört, zugehört.
- ✗ the infinitive (zurückkommen, zurückgeben, zurückfahren, vorbereiten): that is the
  infinitive, not the participle: zurückgekommen, zurückgegeben, zurückgefahren, vorbereitet.
- vorbereiten only (gevorbereitet, gevorbereiten): bereiten already has the inseparable
  prefix be-, so no ge- appears anywhere: vorbereitet. This is the one item where the
  separable prefix is not followed by ge-.

**flashcard_and_miss_hint**: an, auf, aus, ein, mit, vor, zu, zurück, fern are separable, so ge-
sits inside: ab + ge + holt. If the stem has its own inseparable prefix, no ge-: anerkennen → anerkannt.

**later_rung_cue**: Does this verb's prefix split off? That decides where ge- goes.
