Preview only

The app has no look picker: the look follows the current hour of the forecast. These buttons swap the example forecast so each look can be seen.

Settings and mock tools

Wind is the same 0 to 100 user setting as on home (default 30). Each look lets only part of it through. Theme, pause and reduced motion are mock tools; the app follows the system.

Readability check

Worst case per look: darkest and lightest sky stop, with the strongest effect pixel the look can draw sitting under the text after the text keep-out (at most 15% of the effect remains over text). Target 4.5:1 for all card text, small grey text included.
