  Not pack settings: wallpaper and text size stay in their own places (shown greyed
  on the Settings screen here) — a pack never sets them and the picker never offers them.
  Validation order on import: JSON parse → required fields → hex format → known
  mode → AA contrast (4.5:1 body text; accent passes as accent-only at 3:1 vs the
  background or as a fill with a readable text colour on it — which is what lets Thumbline light
  ship #D9F24B). A rejected pack changes nothing. Fonts are approximated with system
  stacks in this mock; the app bundles the real TTFs.
