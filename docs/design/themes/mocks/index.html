All variants

Fonts in this mock are approximated with system stacks (Inter → system sans, IBM Plex Sans → system sans, Nunito → rounded system stack). The app bundles the real TTFs in app/src/main/res/font/; this preview is layout and colour only. The clock uses tabular figures so it does not shift width. Bold versions are separate packs with the same colours and bold text. Christmas packs show snow in the pack's snow colour. No wallpaper photo is part of any pack — the flat background colour stands in for it here.

Thematic dressing (design exploration): the seasonal packs additionally show decoration in this mock only — Halloween gets a corner web with a dangling spider, drifting bats, a floating ghost and a jack-o'-lantern; Diwali gets flickering diyas along the bottom, firework bursts in the sky and a lotus motif (a deliberate nod to Lakshmi — deity figures are deliberately not drawn); Christmas gets string lights, a Santa hat on the clock, a tree and gift boxes on top of the snow. Decorations sit in empty corners only, never under text, and the pack JSON still carries only colours, font and bold — dressing like this would be an app-side presentation choice keyed to the pack family, a possible extension of the format. Thumbline, Sage, Midnight and Rose stay deliberately clean.
